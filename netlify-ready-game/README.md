
# 🎮 Battle Quiz Arena

### Challenge Your Friends. Answer Fast. Win the Battle!

Battle Quiz Arena is a real-time multiplayer quiz game where players can create rooms, invite friends using a room code, and compete by answering quiz questions.

## 🌐 Live Demo

👉 **Play Now:** https://battle-quiz-arena.netlify.app/

## 📂 GitHub Repository

👉 https://github.com/rahulkure2004/battle-quiz-arena

## 📖 About the Project

Battle Quiz Arena is an interactive, browser-based quiz game designed to make learning fun and competitive. Players can create a game room, share the room code with friends, answer multiple-choice questions, and compete for the highest score.

The game combines quiz challenges, a countdown timer, scoring, and multiplayer gameplay in a colorful and user-friendly interface.

## ✨ Features

- 🎯 Multiplayer quiz gameplay
- 🏠 Create and join rooms using a room code
- ⏱️ Timed questions
- 🧠 Multiple-choice quiz questions
- 🏆 Score tracking and final results
- 📚 Different quiz categories
- 🎨 Colorful and interactive user interface
- 📱 Browser-based gameplay
- ⚡ Real-time communication in the server-based version

*Some features depend on the currently deployed version and backend configuration.*

## 🛠️ Technologies Used

## 🎮 How to Play

1. Open the [Live Demo](https://battle-quiz-arena.netlify.app/).
2. Create a new quiz room.
3. Share the room code with a friend.
4. Join the room from another browser or device.
5. Answer the questions before the timer ends.
6. Earn points for correct answers.
7. Compare the final scores and find the winner!

## 🚀 Installation and Setup

### Prerequisites

Install the following tools:

- Node.js
- npm
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/rahulkure2004/battle-quiz-arena.git
```

### Step 2: Open the Project Folder

```bash
cd battle-quiz-arena
```

### Step 3: Install Dependencies

```bash
npm install
```

If the project has separate `client` and `server` folders with their own `package.json` files, install dependencies in those folders as well.

### Step 4: Run the Project

```bash
npm run dev
```

Run only the scripts available in your project's `package.json`. If the frontend and backend run separately, start both using their configured scripts.

### Step 5: Open in Browser

Open the local URL shown in your terminal. For Vite, it is commonly:

```text
http://localhost:5173
```

The backend must be running and correctly configured for multiplayer gameplay.
